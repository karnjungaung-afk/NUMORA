# NUMORA

A Thai-first 2D pixel-art RPG where math challenges power monster battles. Collect original creatures, summon through an in-game coin-only gacha, and challenge friends when the online backend is connected.

## Development

```bash
npm install
npm run dev
```

This repository is being initialized as a fresh Vite + React + TypeScript game project. The initial playable version will include a local single-player battle loop, monster collection, and a fair coin-only summon system. Real online PvP requires a configured realtime backend.
